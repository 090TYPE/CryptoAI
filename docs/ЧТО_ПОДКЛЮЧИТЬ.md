Сейчас всё, что помечено ⏳, работает в **paper / demo / preview** режиме и не тратит реальные средства.
Обновлено: 2026-07-06.

## Статус кода (что уже реализовано в приложении)

- ✅ **Реальный своп по best-route** — код build+sign+send через OpenOcean готов (`AggregatorSwapExecutor`),
  тумблер «Execute BUY via best route» в SWAP-тикете. Чтобы реально отправить сделку: нужен **кошелёк с ключом + gas + RPC** (см. §2).
- ✅ **Live-позиции Hyperliquid** — вкладка «Live Acct» в PERP показывает НАСТОЯЩИЕ позиции подключённого кошелька (keyless, работает сразу).
- ⏳ **Отправка перп-ордеров** (Hyperliquid/GMX) — код-билдер готов, но live-подпись **намеренно закрыта** до проверки на фандированном testnet (§3). Защита средств клиентов.
- ✅ **Полный кросс-чейн портфель** — код готов (`PortfolioAggregatorService`), в портфеле есть поле для ключа. Вставь **ключ Covalent** → холдинги по всем сетям + USD (§4).

## 2. Реальное исполнение свопа (SWAP execution) ⏳💰🔑

Сейчас: агрегатор показывает **только превью** маршрута. Чтобы реально свапать:

- [ ] **Приватный ключ / seed кошелька** для подписи транзакций
      → привязать в настройках кошелька приложения (никому не передавать!).
- [ ] **💰 Нативная монета на gas** в каждой сети, где торгуем
      (ETH на Ethereum/Arbitrum/Base, BNB на BSC, MATIC на Polygon, SOL на Solana и т.д.).
- [ ] **🔑 Надёжный RPC-эндпоинт** (публичные тормозят и режут запросы). Выбрать одного:
      - **Alchemy** — free tier 300M CU/мес, есть почти все EVM-сети. (рекомендую)
      - **Infura** — free tier 3M req/день.
      - **QuickNode** — платный, быстрый.
      - Для Solana: **Helius** (free tier есть) или **QuickNode**.
- [ ] (опц.) **🔑 OpenOcean API-ключ** — если упрёмся в rate-limit бесплатного.

**Что даст:** кнопка Swap реально строит → подписывает → отправляет транзакцию.

## 3. Реальные on-chain перпы (Hyperliquid / GMX / dYdX) ⏳💰🔑

Код подписи Hyperliquid **готов и офлайн-доказан** (подпись восстанавливается в адрес подписанта).
Осталось подтвердить, что сам Hyperliquid принимает подпись — это делается на **testnet** (бесплатно).

### Hyperliquid — шаги до реальных ордеров

1. **Валидация на testnet (бесплатно, делаешь ты):**
   - [ ] Заведи testnet-кошелёк, возьми бесплатные USDC на https://app.hyperliquid-testnet.xyz (faucet).
   - [ ] Прогони харнесс своим testnet-ключом:
     ```bash
     HYPERLIQUID_TESTNET_KEY=0x<твой_testnet_ключ> \
       dotnet test CryptoAITerminal.Core.Tests --filter Live_testnet_order_is_accepted
     ```
     Зелёный тест = Hyperliquid принял подпись (`status:ok`). Красный — пришли мне ответ, поправлю.
2. **Включение в приложении:**
   - [ ] Вкладка PERP → **Live Acct** → панель **LIVE ORDER**: галка «Enable live orders», «Testnet».
   - [ ] Импортируй trade-кошелёк (EVM, не watch-режим) во вкладке Wallet.
   - [ ] Ставь ордер — сначала на testnet, убедись что видно в Live Acct.
3. **Переход на mainnet (реальные деньги):**
   - [ ] 💰 Депозит USDC на Hyperliquid (bridge с Arbitrum).
   - [ ] Сними галку «Testnet». (Сработает live-guard приложения.)
   - [ ] **Рекомендация:** используй Hyperliquid **agent/API-кошелёк** (отдельный одобренный ключ), а не главный seed — безопаснее для продажи.

### GMX v2 (Arbitrum) — чтение готово, отправка gated

## 4. Полноценный портфель (все сети + PnL) ⏳🔑

Сейчас: балансы читаются **только для текущей сети** кошелька, без cost-basis.
Для кросс-чейн холдингов и PnL по позициям нужен один keyed holdings-API:

- [ ] **🔑 Alchemy** — `getTokenBalances` + Portfolio API. Free tier хватает. (рекомендую — он же нужен для п.2)
- [ ] или **🔑 Covalent (GoldRush)** — балансы + история по многим сетям. Free tier 100k credits.
- [ ] или **🔑 Moralis** — Web3 Data API, балансы + цены. Free tier есть.
- [ ] (для PnL) — тот же провайдер даёт историю транзакций → считаем среднюю цену входа.

**Что даст:** портфель по ВСЕМ сетям сразу + нереализованный PnL по каждому токену.

## 7. Приоритет подключения (мой совет)

Если брать один сервис первым — берите **Alchemy** (🔑, free tier):
он сразу закрывает **RPC для свопа (п.2)** + **портфель по всем сетям (п.4)**.

Порядок:
1. **Alchemy** (free) — разблокирует свап + портфель.
2. **Кошелёк + немного gas** 💰 — чтобы реально отправлять транзакции.
3. **Flashbots RPC** (free) — MEV-защита, почти бесплатно.
4. **Anthropic/OpenAI key** — если хочется живой AI.
5. **Депозиты на перп-площадки** 💰 — только когда точно решишь торговать перпами вживую.
